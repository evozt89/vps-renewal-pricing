## 低价vps到底便宜在哪，钱又藏在哪里

低价 VPS 的便宜分两种，混淆它们是新手多花钱的主要原因。

一种是“真便宜”：年付特价把单价压到几美元一个月，商家靠走量赚钱。RackNerd 的 1 核 / 1GB / 20GB / 3TB 流量套餐年付 $21.99，折合每月不到 $2，美国十来个机房一个价，属于这一类。

另一种是“先便宜后贵”：促销价只覆盖首期，续费时价格翻上去。第三方测评对这类商家的描述很一致：首单价 2 到 4 倍的续费很常见，$12 年付的套餐第二年续到 $24–36 并不少见。行业层面的统计也支持这个判断——自助管理型 VPS 的 4GB 内存套餐促销价约 $4–7/月，续费价通常是首期的 1.3–3 倍。
